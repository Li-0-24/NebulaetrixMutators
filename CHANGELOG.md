# Changelog

## 1.0.0

Initial standalone release. Split out from CiCi's Trinket & Binding Framework v1.x where the modes shipped bundled.

- 13 mutators register via the framework's new `CustomModeRegistry` API.
- 15 named combos including "Why" (every shippable mode at once).
- Marathon redirects Campaign to the 173-level playlist.
- Backward Mode (elkcunK etihW) gated as WIP with the framework's disabled-lock visual.
- AssetBundle (`more_mutators_assets`) ships alongside the DLL.
- Per-run best-score persistence in `MutatorSaves/save.json`.
